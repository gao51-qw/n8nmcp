# Legacy root reports (2025 – mid-2026)

These 36 Markdown files used to sit untracked in the repository root. They are
progress reports, guides and analyses written while the project still had the
retired Express API, the `apps/` dashboard workspace, Plan B front/back split,
the in-memory orchestrated-tool confirmation flow and the Cloudflare/Sites
experiments. None of them describe the current architecture; `AGENTS.md` and
`docs/superpowers/plans/` are the source of truth.

They are kept locally for reference only. The report bodies are git-ignored
(see `.gitignore`) because this repository is public and several of them
contain historical security findings and environment details. Only this
README is tracked.

Current audit: `docs/audits/PROJECT_AUDIT_2026-11-03.md`.
